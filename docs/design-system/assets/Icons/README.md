Ícones do Phosphor (estilo regular, v2.1.1, licença MIT), em 20px. Estas cópias estão pintadas em `ink-muted` (#9f9f9f) para aparecerem nas prévias; no código, use o pacote `@phosphor-icons/react` com `currentColor`, para o ícone herdar a cor do texto.

| Ícone | Uso |
| --- | --- |
| `magnifying-glass` | Busca de jogadores |
| `eye` | Acompanhar jogador |
| `eye-slash` | Encerrar acompanhamento |
| `note-pencil` | Relatório: escrever, editar, criar correção |
| `list-numbers` | Shortlist |
| `arrows-left-right` | Comparar dois jogadores |
| `dots-six-vertical` | Alça de arrastar na shortlist |
| `arrow-left` | Voltar |
| `x` | Fechar e remover alvo |
| `arrow-clockwise` | Tentar de novo |
| `sign-out` | Sair da conta |
| `plus` | Adicionar à shortlist, novo relatório |
| `check` | Finalizar relatório, confirmação |
