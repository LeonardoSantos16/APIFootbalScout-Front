# ChangeChip

Etiqueta de variação no acompanhamento, verde para alta e vermelha para queda, sempre com sinal e palavra.

- **O consumidor fornece:** `direction` (`up` ou `down`) e o texto como `children`.
- O texto sempre começa com o sinal (`+` ou `−`) e nomeia o que mudou; a cor sozinha não carrega o significado.
- Não use para "sem mudança relevante": esse estado é neutro e não leva chip.
